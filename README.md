# Моят гараж — инвентар и Сервиз

Новата секция „Сервиз“ позволява добавяне/редактиране на автомобили и история на обслужването:
- регистрационен номер, собственик, марка, модел, двигател, конски сили;
- търсене по регистрационен номер;
- дейност, километри, дата и коментар за всяко обслужване;
- JSON архивът включва и автомобилите и записите за обслужване.

Данните засега се пазят локално в браузъра на устройството. Google Drive синхронизацията не е включена в тази версия. Използвай Архив за резервни копия.
